# 📁 Public Binder (퍼블릭 바인더)

**Public Binder**는 대용량 로컬 파일 및 다양한 문서 페이지를 비파괴적으로 제어, 편집, 검색, 정렬할 수 있도록 설계된 강력한 데스크톱 파일 관리 및 문서 조립 플랫폼입니다. 

본 프로그램은 서버 통신 없이 **100% 사용자의 PC 로컬 환경에서 구동**되므로, 기업의 물리적 망분리 환경이나 극비 보안 문서 취급에 최적화되어 있습니다. 작업 공간은 목적에 따라 크게 두 가지 모듈로 구분됩니다.
* **Page Lab**: 문서 페이지 단위의 가상 해체 및 비파괴적 조립 도구
* **Folder Lab**: 대규모 로컬 저장소 탐색 및 SQLite FTS5 기반의 심층 본문 검색을 지원하는 3단 레이아웃 가상 스테이징 탐색기

## 🌟 시스템 구성 및 주요 모듈 상세 설명

### 1. 📄 Page Lab (페이지 랩) - 페이지 단위 조립 및 편집
여러 형식의 문서를 가져와 원본의 손상 없이 페이지를 가상으로 해체(Deconstruct)하고, 마우스 드래그 앤 드롭을 통해 직관적으로 재정렬/병합/분류하여 최종 문서 패키지를 빌드하는 비파괴적 페이지 편집 엔진입니다.

* **다양한 포맷의 자동 PDF 변환**:
  * PDF 파일뿐만 아니라 한글 문서(`.hwp`, `.hwpx`)를 드래그 앤 드롭으로 가져올 때, 백엔드에서 사용자 PC에 설치된 한컴오피스 한글 엔진(COM Automation API)을 직접 호출하여 무손실 PDF로 자동 변환합니다.
  * 변환된 PDF는 고성능 문서 파싱 라이브러리인 PyMuPDF(fitz)를 통해 각 페이지별 고해상도 PNG 이미지(썸네일)로 렌더링되어 프론트엔드로 즉시 전송됩니다.
* **비파괴적 페이지 제어 (Non-Destructive Page Manipulation)**:
  * 화면상의 썸네일 노드를 잡고 원하는 분류 폴더로 드래그하여 배치합니다.
  * 우상단 퀵 툴바 및 개별 카드 오버레이를 통해 **페이지 90도 회전**, **임시 제외(Dim/Exclude)** 처리가 가능하며, 원본 파일의 디스크 바이너리는 절대 손상시키지 않고 최종 내보내기 시점에만 가상 명세서(Payload)를 기반으로 새 문서를 실시간 합성합니다.
* **표준 다중 선택 지원 (UX)**:
  * 마우스 단일 클릭 외에도 `Shift` 키(연속 범위 선택), `Ctrl` 키(개별 추가 및 토글 제외) 조합을 완벽히 지원하여, 수백 장 단위의 문서 묶음에서 필요한 페이지들만 한눈에 골라내고 분류 폴더로 Copy-on-Drag 할 수 있습니다.
* **컨텍스트 메뉴 기반 개별 페이지 네이밍**:
  * 내보내기 작업 전에 각 페이지 썸네일을 우클릭하여 **'페이지 이름 지정'** 기능을 수행할 수 있습니다. 
  * 이렇게 지정된 이름은 개별 페이지 분할 내보내기 시 파일명이 되며, 다운로드 후에 파일명을 하나하나 다시 바꾸는 번거로운 과정을 완벽하게 방지합니다.
* **다양한 배출(Export) 옵션**:
  * **통합 다운로드 (PDF)**: 지정된 폴더 내의 가상 페이지들을 순서대로 하나의 PDF 파일로 결합하여 내보냅니다. 회전 값과 빈 페이지(간지)가 그대로 실시간 반영됩니다.
  * **파일별 다운로드 (ZIP)**: 폴더 내의 각 페이지들을 개별 낱장 PDF로 변환하고, 사용자가 입력한 페이지명을 파일명으로 지정하여 하나의 ZIP 파일로 패키징해 내려받습니다.
  * **다중 폴더 이중 패키징 (이중 ZIP)**: 사용자가 다수의 분류 폴더를 다중 선택(`Ctrl`/`Shift` 사용)하여 내보낼 경우, 각 폴더의 계층을 보존한 폴더별 ZIP 파일들을 다시 하나의 최상위 ZIP 파일로 묶어서 제공합니다 (ZIP 안의 ZIP 구조).

### 2. 🗂️ Folder Lab (폴더 랩) - 3단 분할 탐색 및 심층 본문 검색
대규모 로컬 저장소의 파일 시스템을 모니터링 및 시뮬레이션하여, 문서를 원하는 논리 구조로 재배치하고 본문 심층 검색을 통해 기업의 지식 자산을 체계화하는 전문 파일 탐색기 공간입니다.

* **Total Commander 스타일 3단 분할 레이아웃**:
  * **좌측 패널 (Local Explorer)**: 시스템 드라이브의 실제 파일 트리를 지연 로딩(Lazy Loading) 및 비동기 방식으로 신속하게 탐색합니다.
  * **중앙 전송바 (Transfer Action Bar)**: 좌측 탐색기에서 다중 체크박스로 선택한 파일/폴더들을 우측 작업 패널로 안전하고 빠르게 전송합니다.
  * **우측 패널 (Staging / Real Dual Mode)**:
    * **가상 스테이징 작업 (Virtual Staging)**: 실제 파일 시스템 변경 없이, 가상 트리 공간 속에서 논리적인 폴더 구조를 마음껏 생성하고, 인라인 더블클릭으로 이름을 바꾸며, 마우스 드래그 앤 드롭으로 노드를 자유롭게 편집합니다.
    * **실시간 로컬 작업 (Real-time Local Workspace)**: 실제 로컬 드라이브 경로를 타겟으로 연결하여 파일 복사, 이동, 삭제 등의 파일 시스템 쓰기 작업을 즉각적으로 수행하고 반영합니다.
  * **하단 드로어 (Deep Search Panel)**: SQLite FTS5 기반의 심층 문서 검색기와 해당 본문 문맥(스니펫) 미리보기 패널을 상시 배치하여 시선 이동을 최소화합니다.
* **SQLite Trigram FTS5 기반 고성능 한글 문서 검색 엔진**:
  * 한글 텍스트 분석에 최적화된 SQLite **Trigram 토크나이저**를 내장하여 자음/모음 단위의 검색 매칭이 비약적으로 빠릅니다.
  * `.hwp`, `.hwpx`, `.pdf`, `.pptx`, `.xlsx`, `.docx`, `.txt`, `.md` 등 구조가 제각각인 비정형 문서들의 텍스트 본문을 정교하게 파싱하여 인덱싱 테이블에 등록합니다.
  * 검색 시 매칭 단어가 포함된 문맥 앞뒤의 200 단어를 추출하고 일치 부분을 `<mark>` 태그로 형광펜 처리하여 하단 미리보기 패널에 즉시 표시합니다.
  * 검색 결과를 마우스로 잡아 드래그하여 우측 가상 스테이징으로 던지면, 해당 파일이 스테이징 구조 내부로 자동으로 추가/큐레이션됩니다.
* **하이어러키를 유지하는 탐색기 UX**:
  * 우측 마우스 컨텍스트 메뉴를 통해 윈도우 OS 탐색기 열기 및 기본 앱 실행을 연동합니다.
  * 새 폴더 생성 시 전체 트리가 리프레시되면서 닫히는 현상을 방지하고, 변경이 일어난 부모 경로의 하위 자식 노드만 부분 갱신(Partial Refresh)하여 사용자가 펼쳐놓은 하이어러키 폴더 구조의 확장 상태를 고스란히 유지합니다.

## 🛠️ 백엔드 문서 파싱 아키텍처 (Document Parser & OLE Details)

Public Binder의 텍스트 파서는 포맷별 라이브러리가 없는 극도로 열악한 로컬 환경에서도 문서 내용을 안전하게 추출할 수 있도록 파일 바이너리를 직접 디코딩하는 강력한 파서 모듈(`backend/document_parser.py`)을 포함하고 있습니다.

1. **PDF**: `PyMuPDF (fitz)` 모듈을 호출하여 페이지 텍스트 영역을 비동기로 추출합니다.
2. **HWPX / Office Open XML (DOCX, PPTX, XLSX)**:
   * 이 규격의 파일들은 구조적으로 다수의 XML 파일을 압축하고 있는 ZIP 포맷입니다.
   * 파일 압축을 스트림으로 해제한 뒤, 문서 본문 내용이 담긴 핵심 XML 파일(`word/document.xml`, `ppt/slides/slideN.xml`, `xl/sharedStrings.xml`)을 찾아 ElementTree 라이브러리로 순회하고, `<w:t>`, `<a:t>`, `<hp:t>` 등 문자열을 보유한 말단 텍스트 태그 내의 데이터들을 추출해 결합합니다.
3. **HWP 5.0 (Binary HWP)**:
   * 한글 5.0 구조 파일은 윈도우의 복합 문서 파일 구조인 **OLE(Object Linking and Embedding) 컨테이너**입니다.
   * `olefile` 모듈을 이용하여 컨테이너 내부의 구조적 스트림들을 탐색합니다.
   * **1차 시도 (PrvText)**: 한글 문서가 생성될 때 캐싱되는 유니코드 텍스트 미리보기 스트림인 `PrvText`를 우선 추출합니다. 이 방식은 구조가 단순하고 처리 속도가 빠릅니다.
   * **2차 시도 (BodyText/SectionN 및 zlib 압축 해제)**: `PrvText`가 없거나 암호화되어 있을 경우, 본문에 해당하는 `BodyText/SectionX` 이진 파일들을 차례대로 로드합니다. 각 섹션의 바이너리는 zlib 알고리즘으로 압축되어 있으므로, 윈도우 헤더 형식에 대응하기 위해 raw deflate(`wbits = -15`) 및 표준 zlib 디컴프레션을 단계별로 수행합니다.
   * **레코드 파싱 (Tag ID 67)**: 압축이 풀린 바이너리 스트림에서 한글 문서의 문단 텍스트 레코드 식별자(`HWPRCD_PARA_TEXT` = `67`)를 비트 연산으로 필터링하고, 본문 문자열을 지칭하는 바이트열만 추출하여 UTF-16LE 문자셋으로 환원합니다. 제어 문자(바이너리 코드 32 미만)는 클렌징 루프를 거쳐 깔끔하게 지워냅니다.

## 🔒 보안 아키텍처 및 방어 기법 (Security Designs)

본 애플리케이션은 보안 전문가의 가이드라인에 따라 다음과 같은 안전 조치들이 코드 전반에 구현되어 있습니다.

* **경로 조작(Path Traversal) 차단**:
  * 사용자가 지정하는 폴더명 또는 다운로드 파일명에 포함될 수 있는 상위 경로 기호(`../`, `..\`) 및 시스템 차단 특수 기호(`\`, `/`, `:`, `*`, `?`, `"`, `<`, `>`, `|`)들을 정규표현식 기반의 `safe_filename()` 백엔드 필터로 완벽히 걸러내어, 원치 않는 임의 디렉토리에 파일이 쓰여지는 현상을 방어합니다.
* **XSS (HTML 인젝션) 방어**:
  * 프론트엔드(`app.js`, `folderlab.js`)에서 사용자 지정 파일명이나 본문 검색 결과, 가상 폴더 트리 노드를 브라우저 화면에 동적으로 그릴 때 사용자 입력값이 HTML 요소로 강제 해석되지 않도록 `escapeHTML()` 보안 필터링 함수를 필수로 거치게 하여 DOM 인젝션을 차단합니다.
* **백엔드 매개변수 유효성 검증 (Input Validation)**:
  * 백엔드 API인 `export_data` 등은 호출 시 클라이언트가 전달한 내보내기 종류 변수(`export_type`이 `single_pdf`, `single_zip` 포맷에 정확히 들어맞는지), 페이지 회전 범위 수치(`rotation`이 `0`, `90`, `180`, `270` 중 하나에 포함되는지)를 재검사하여 오동작을 미연에 방지합니다.
* **보안 운영 및 실행 권한 가이드**:
  * 한컴오피스 COM 객체 제어 및 로컬 파일의 비파괴 처리를 위해 시스템에 깊숙이 접근하므로, 악의적으로 조작된 HWP 변환 시 취약점에 노출되지 않도록 **Public Binder 실행 시 반드시 관리자 권한이 아닌 일반 사용자 권한으로 프로그램을 실행**하십시오.
  * 배포 시 바이너리의 위변조 방지를 위해 실행본 `.exe` 파일의 SHA-256 체크섬 해시값을 대조하는 것을 권장합니다.

## 💻 설치 및 개발 구동 가이드

### 1. 사전 요구사항 (Prerequisites)
* **OS**: Windows 10 / 11 (64bit)
* **Python**: Python 3.10 이상
* **MSVC Runtime**: C++ 라이브러리 및 SQLite ctypes 호출을 위해 필요
* **한컴오피스 한글**: HWP/HWPX 문서의 완벽한 레이아웃 보존 PDF 변환을 위해 필수 설치되어 있어야 합니다.

### 2. 패키지 설치
터미널을 열고 프로젝트 루트 경로에서 다음 명령을 실행하여 종속성 라이브러리를 설치합니다.
```bash
pip install -r requirements.txt
```
*설치되는 핵심 라이브러리:*
* `pywebview==5.0.5` (로컬 크롬 엔진 연동 GUI 윈도우 생성)
* `PyMuPDF>=1.26.7,<1.27` (핏츠 PDF 제어 및 썸네일 렌더러)
* `pywin32==308` (한컴 COM 객체 통신용 윈도우 API 래퍼)

### 3. 개발용 실행
코드를 수정하면서 데스크톱 앱을 바로 구동하려면 아래 명령을 사용하십시오.
```bash
python main.py
```

### 4. 테스트 코드 실행
본문 텍스트 추출 모듈의 작동 무결성을 검증하려면 다음 유닛 테스트 명령을 수행합니다.
```bash
python -m unittest discover -s tests
```

## 📦 단일 실행파일 (.exe) 빌드 및 패키징

개발이 완료된 소스코드를 공공기관이나 기업 사용자에게 배포하기 위해, 파이썬이 설치되어 있지 않은 윈도우 PC 환경에서도 독립적으로 실행되는 단일 무설치 파일(`.exe`)을 빌드할 수 있습니다.

본 프로젝트는 최적의 빌드 환경 설정을 보유한 `PageLab.spec` 구성 파일을 기본 제공하므로, 아래 명령만으로 편리하게 빌드를 완료할 수 있습니다.

```bash
# PyInstaller 패키징 진행
pyinstaller PageLab.spec
```

* **빌드 결과물 위치**: 빌드가 완료되면 프로젝트 루트에 `dist/` 폴더가 생성되며, 그 아래 `dist/PageLab` 경로 내부에 더블클릭으로 즉시 구동 가능한 실행파일 및 연동 라이브러리 패키지들이 위치하게 됩니다.
* **주요 패키징 제어 내역 (`PageLab.spec`)**:
  * 프론트엔드 리소스 폴더(`frontend/`)를 실행파일 실행 경로 내부로 함께 복사하도록 구성 (`datas`).
  * PyMuPDF 내부 ctypes DLL 탐색 및 SQLite Trigram 토크나이저 연동 모듈을 안전하게 패키징에 누락 없이 포함하도록 조정.
  * 콘솔 창이 화면 뒤로 노출되지 않도록 `console=False` 설정 적용.
