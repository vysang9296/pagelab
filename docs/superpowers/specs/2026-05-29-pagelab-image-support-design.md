# Page Lab 이미지 포맷 지원 설계서 (Design Specification)

## 1. 개요 (Overview)
* **목적**: 퍼블릭 바인더의 Page Lab 모듈에 이미지 포맷(`.png`, `.jpg`, `.jpeg`) 지원을 추가하여, 문서 조립 과정에서 스캔 이미지 및 사진 자료를 비파괴적으로 함께 결합하고 정렬할 수 있게 합니다.
* **적용 범위**: Page Lab 파일 다이얼로그 업로드, 드래그 앤 드롭 업로드, 백엔드 이미지-PDF 실시간 변환, 최종 PDF/ZIP 병합 배출.

## 2. 요구사항 및 상세 설계 (Detailed Design)

### 2.1 파일 선택 필터 확장
* **파일**: `main.py`
* **함수**: `upload_files`
* **설계**: 파일 선택 다이얼로그의 파일 필터 문자열에 이미지 확장자를 추가합니다.
  * 기존: `Document Files (*.pdf;*.hwp;*.hwpx)`
  * 변경: `Document Files (*.pdf;*.hwp;*.hwpx;*.png;*.jpg;*.jpeg)`

### 2.2 백엔드 실시간 이미지-PDF 변환 파이프라인
* **파일**: `main.py`
* **함수**: `process_files`
* **설계**: 
  * 파일 리스트 순회 중 이미지 파일 확장자(`.png`, `.jpg`, `.jpeg`)가 검출되면, 백엔드 임시 디렉토리에 고유 UUID를 가진 PDF 파일 경로를 예약합니다.
  * PyMuPDF(`fitz`)를 사용하여 이미지 파일을 열고, `convert_to_pdf()` 메서드를 통해 원본 비율과 해상도를 100% 보존한 PDF 바이너리를 생성합니다.
  * 생성된 PDF 바이너리를 지정된 임시 경로에 물리 파일로 쓰고, 이 임시 PDF 파일 경로를 후속 썸네일 렌더링 및 결합 연산에 전달합니다.

### 2.3 데이터 흐름도
```
[사용자 파일 드롭 / 선택]
        │
        ▼ (확장자 판별)
 ┌──────┴────────────────────────┐
 │   .pdf         .hwp/.hwpx     │ .png/.jpg/.jpeg
 │ (원본 로드)    (한컴 COM 변환) │ (PyMuPDF 실시간 이미지 변환)
 └──────┬──────────────┬─────────┘
        │              │
        └──────┬───────┘
               ▼
   [임시 PDF 파일 생성 완료]
               │
               ▼
     [페이지별 썸네일 렌더링]
               │
               ▼
     [프론트엔드 전송 및 정렬/편집]
```

## 3. 예외 처리 및 검증 계획 (Exception Handling & Verification)

### 3.1 예외 처리
* 손상된 이미지 파일 또는 알 수 없는 파일 스트림 업로드 시, PyMuPDF 로딩 과정에서 예외가 발생하므로 `try-except` 구문에서 오류 메시지를 에러 얼럿(Base64 인코딩 메시지)을 통해 프론트엔드로 안전하게 전달합니다.
* 사용한 `fitz.Document` 인스턴스는 반드시 `close()`하여 메모리 누수를 방지합니다.

### 3.2 수동 검증 시나리오
1. **업로드 필터 검증**: `+` 버튼 클릭 시 PNG, JPG 파일이 탐색기 상에 필터링되어 나타나며 선택이 가능한지 확인합니다.
2. **드래그 앤 드롭 검증**: 로컬 컴퓨터의 사진 파일(PNG 등)을 화면 중앙 영역에 놓았을 때 썸네일로 정상 변환되는지 확인합니다.
3. **편집 및 최종 결합 배출**:
   * 이미지 페이지의 각도가 정상적으로 돌아가는지 확인합니다.
   * 이미지 페이지와 한글 페이지를 섞은 뒤 통합 PDF로 내보내어, 최종 결과물 내에서 이미지가 원본 해상도 비율 그대로 한 페이지를 이루며 출력되는지 확인합니다.
