# Page Lab 사용성 및 내보내기 개선 설계서 (Page Lab Usability Spec)

이 문서는 Page Lab의 개별 페이지 다중 선택(체크박스), Shift 범위 선택, 페이지 우클릭 폴더 보내기, 그리고 명시적인 그룹 내보내기 버튼 추가에 관한 설계 스펙을 정의합니다. 
사용자의 피드백을 반영하여 테스트 케이스 검증 목록을 대폭 강화하여 작성하였습니다.

## 1. 목적 (Goal)
Page Lab을 사용할 때 마우스 드래그 앤 드롭에 의존하던 조작 방식을 개선하고, 다중 선택의 편의성을 높이며, 내보내기 기능의 시각적 발견성을 극대화합니다. 또한, 코드 안전성을 위해 다양한 단위 테스트 시나리오를 설정합니다.

---

## 2. 요구사항 및 상세 사양 (Requirements)

### 2.1 개별 페이지 카드 체크박스 및 줌 돋보기 UI 추가
- **마크업 및 스타일**:
  - [app.js](file:///c:/Users/kyung/.gemini/antigravity/Lab/frontend/app.js)의 `createPageCard`에서 생성되는 각 `.page-card` 요소 내부에 선택 토글을 나타낼 체크박스 `<input type="checkbox" class="page-checkbox">`를 추가합니다.
  - 마우스 클릭 시 카드 본문 전체 어디를 클릭해도 선택이 활성화되도록 이벤트를 결합하되, 2번 연속 클릭(더블클릭)과의 조작 혼선을 방지하기 위해 다음과 같이 구성합니다:
    - **Single Click**: 해당 카드의 체크 상태를 토글(선택/해제).
    - **Hover State Overlay**: 이미지 위에 마우스를 갖다 대면 기존의 회전/삭제 외에 추가로 **`🔍` (확대)** 돋보기 아이콘 버튼을 노출시킵니다. 이 버튼을 누르면 즉시 고화질 확대 팝업(`openZoom`)이 실행됩니다. (더블클릭 또한 기존처럼 줌 동작을 유지하여 양방향 지원)

### 2.2 Shift + Click 범위 선택 고도화
- 첫 번째 클릭 지점(`lastClickedThumbId`)과 현재 `Shift + Click`을 한 지점 사이의 모든 카드 목록을 검색하여 일괄 선택(`.selected` 클래스 추가 및 내부 체크박스 `.checked = true` 설정) 처리합니다.
- 범위 바깥의 이미 선택되어 있던 노드들은 선택 상태가 그대로 유지됩니다.
- 센터 뷰어 상단 툴바에 `☑ 전체 선택` 및 `☐ 선택 해제` 버튼을 추가합니다.

### 2.3 페이지 우클릭 "분류 폴더로 보내기" 메뉴 제공
- 페이지 우클릭 시 호출되는 `showPageContextMenu(e, pId)` 함수에 **`📁 분류 폴더로 보내기`** 항목을 추가합니다.
- 마우스를 올리면 현재 존재하는 모든 분류 폴더(Groups) 목록이 서브메뉴(Submenu)로 슬라이드되거나 나열되어 나타납니다.
  - 서브메뉴 클릭 시: 현재 선택되어 있는 모든 페이지 카드가 해당 타겟 분류 폴더의 `pageIds` 목록으로 즉시 일괄 전송(복사)됩니다.

### 2.4 분류 폴더 내보내기 버튼 시각화
- 우측 "분류 폴더 (Groups)" 패널의 상단 새 폴더 버튼 옆에 명시적인 **`📤 내보내기 (Export)`** 버튼을 추가합니다.
- 선택된 분류 폴더들에 대한 내보내기 다이얼로그 모달을 띄워 병합 PDF, 개별 PDF ZIP, 이중 ZIP 등을 마우스 우클릭 없이 직관적으로 선택해 다운로드할 수 있게 유도합니다.

## 3. 검증 계획 및 강화된 단위 테스트 케이스 (Verification & Test Cases)

사용자가 테스트 케이스 강화를 적극 요청함에 따라 백엔드 가공 로직 및 데이터 정합성에 대해 다음과 같이 다각도 단위 테스트를 설계하고 구현합니다:

### 3.1 추가될 백엔드 단위 테스트 목록 (`tests/test_export_improvements.py`)
1. **`test_safe_filename_path_traversal`**:
   - 상위 경로 탈취 공격 시도(예: `../../etc/passwd`, `..\\..\\windows`)가 들어오는 경우 `safe_filename` 함수가 디렉터리 경로 기호를 모두 제거하고 안전하게 파일명만 남기는지 확인합니다.
2. **`test_safe_filename_reserved_words`**:
   - Windows 예약어(예: `CON`, `PRN`, `AUX`, `NUL`, `COM1`) 또는 특수문자(`*?:"<>|`)가 포함된 파일명이 안전하게 필터링되는지 검증합니다.
3. **`test_rotation_validation_edge_cases`**:
   - `export_data` 호출 시 payload 내의 rotation 값 중 `90, 180, 270, 0` 이외의 잘못된 값(예: `360, -90, 45, 9999`)들이 전부 강제로 `0`으로 정상 변환되는지 다양한 깊이의 페이로드 구조에 대해 전수 테스트합니다.
4. **`test_export_data_empty_payload`**:
   - 빈 페이로드나 잘못된 형식의 데이터가 `export_data`로 유입될 때 예외 크래시를 방지하고 정상적으로 `False` 처리를 반환하는지 안전성을 검증합니다.
5. **`test_export_data_nested_zip_structure`**:
   - 2단계 다중 내보내기(이중 ZIP) 형식에 맞는 복잡한 트리 구조의 Payload에 대해서도 각 하위 PDF의 페이지 회전값이 정상적으로 검증 및 가공되는지 테스트합니다.

### 3.2 수동 UI 검증 시나리오
1. **체크박스 토글 검증**: 임의의 카드를 마우스로 클릭하여 파란 테두리와 체크박스 체크가 동시에 켜지고 꺼지는지 확인합니다.
2. **Shift 범위 선택 검증**: 1번 카드를 클릭하고 4번 카드를 `Shift + Click` 했을 때, 2번과 3번 카드가 모두 함께 켜지는지 검증합니다.
3. **돋보기 버튼 및 더블클릭 줌 검증**: Hover 시 나타나는 돋보기 아이콘 클릭 및 카드 더블클릭 시 줌 모달이 정상 활성화되는지 확인합니다.
4. **분류 폴더 보내기 검증**: 페이지 2개를 선택한 상태로 우클릭하여 `분류 폴더로 보내기 > [특정 폴더]`를 클릭했을 때 드래그 없이 해당 폴더로 일괄 전송되는지 확인합니다.
5. **명시적 내보내기 버튼 검증**: 우측 패널의 `내보내기` 버튼 클릭 시 팝업을 거쳐 다운로드가 정상 수행되는지 확인합니다.
